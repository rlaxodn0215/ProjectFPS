If you use generative AI in your project, the files in this folder
will assist your AI agents when working with the Dialogue System.

If you're using Unity AI, select menu item Edit > Preferences. 
In the AI > Skills section, locate the dialogue-system-for-unity-* skills and 
pixel-crushers-common-* skills and change the dropdowns from Deny to Allow.

If you're using Claude, move the contents (subfolders) of the Skills folder 
into a folder named .claude/skills/ in your main project folder.  
(The .claude folder should be on the same level as your project's Assets folder.)

If you're using a different AI system, you may need to move the contents of 
the Skills folder into a different location such as .agents/skills/ for
Codex.
