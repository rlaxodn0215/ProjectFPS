This folder contains the Dialogue System's source code. To support easy
switchingbetween source code and compiled DLLs, the Dialogue System uses
wrapper classes located in the Wrappers folder.

The Dialogue System uses the Pixel Crushers Common code library, located
in Plugins/Pixel Crushers/Common.

If you want to use assembly definition files (asmdefs), import 
DialogueSystemAssemblyDefinitions.unitypackage.
Note: The asmdefs already have references to common Unity packages such
as TextMesh Pro and Cinemachine. If you enable other options in the 
Welcome window, you may need to add references to their asmdefs in the
Dialogue System's asmdefs.
